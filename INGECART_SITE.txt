HOW TO ADD OR EDIT DOCUMENTS (js/main.js)
--------------------------------------------------------------------------------

  Open js/main.js and locate the `branchDocuments` object at the top.

  Each branch has this shape:

    branchKey: {
      title: "Display name for the modal header",
      description: "Short subtitle shown below the modal title",
      documents: [
        { name: "Document title", type: "PDF or XLSX", detail: "Short note" },
        ...
      ]
    }

  To add a document to an existing branch:
    - Find the branch key (engineering / automation / operations / academy)
    - Append a new object to its `documents` array
    - Update the badge count in the matching <span class="badge"> in index.html

  To add a new branch:
    1. Add a new key to `branchDocuments` in js/main.js
    2. Add a new <article class="branch-card card"> block in index.html
       with data-open-documents="yourNewKey" on its button
    3. Add a matching branch image SVG in assets/images/

HOW TO USE THE SITE LOCALLY
--------------------------------------------------------------------------------

  This is a pure static site — no build step or server required.

  Option A: Open directly in a browser
    - Double-click index.html  (works for all content except Google Fonts,
      which requires internet access)

  Option B: Simple local server (recommended for accurate preview)
    - Python 3:   python -m http.server 8000
                  Then open http://localhost:8000 in your browser
    - Node.js:    npx serve .
                  Then open the printed local URL

GITHUB PAGES DEPLOYMENT
--------------------------------------------------------------------------------

  This repository is already configured for GitHub Pages hosting.

  Steps to activate (one-time, via GitHub):
    1. Go to the repository on GitHub
    2. Settings → Pages
    3. Source: Deploy from a branch
    4. Branch: main (or whichever branch you merge this work into)
    5. Folder: / (root)
    6. Save — the site will be live at https://senarzuniga.github.io/

  After any push to the selected branch, GitHub Pages rebuilds automatically.
  Typical deploy time: 1–3 minutes.

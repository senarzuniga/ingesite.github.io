INSTRUCCIONES CORRECTAS DE CARGA DE VIDEOS Y DOCUMENTOS (REPO ACTUAL)

Estado validado en este repo:
- La libreria publica de videos esta en public/videos.
- El listado visible se renderiza desde public/videos/index.html.
- Cada video puede tener pagina propia en public/videos/<slug>.html.
- En este momento existen dos almacenes de video: assets/videos y public/videos.
- Para evitar problemas de rutas en modo local (file:///), usa como referencia principal los archivos dentro de public/videos cuando el reproductor este dentro de public/videos.

RECOMENDACION OPERATIVA
- Mantener una copia original en assets/videos (archivo maestro).
- Mantener la copia publica en public/videos (archivo servido en la libreria de videos).
- En las paginas dentro de public/videos, usar rutas locales del mismo directorio cuando sea posible:
  - Ejemplo correcto: TRUCKLOADING%20SYSTEM.mp4
  - Evita depender de ../../assets/videos/... si no es necesario.

1) PREPARAR NOMBRE DE ARCHIVO
- Usa nombre web-friendly: minusculas, ASCII, guiones, sin acentos ni espacios.
- Si llega con espacios o mayusculas, puede funcionar, pero no es lo ideal para mantenimiento.

2) COPIAR ARCHIVOS
Ejemplo PowerShell:

Copy-Item -Path "C:\ruta\mi-video.mp4" -Destination "assets/videos/mi-video.mp4"
Copy-Item -Path "C:\ruta\mi-video.mp4" -Destination "public/videos/mi-video.mp4"

3) ANADIR / ACTUALIZAR TARJETA EN public/videos/index.html
- Duplica una tarjeta <article class="card"> y cambia:
  - Titulo
  - source src
  - enlace de descarga
- Si la tarjeta esta dentro de public/videos/index.html y el mp4 tambien esta en public/videos, usa:
  - src="mi-video.mp4"
  - href="mi-video.mp4"

4) PAGINA INDIVIDUAL DEL VIDEO (OPCIONAL PERO RECOMENDADA)
- Crear/editar public/videos/mi-video.html con:
  - <source src="mi-video.mp4" type="video/mp4">
  - boton descarga href="mi-video.mp4"
- Para estilos en local y en web, usa:
  - ../../css/styles.css
  - y fallback https://ingesitehub.netlify.app/css/styles.css

5) ENLAZAR DESDE SOLUCIONES
- Si una pagina de producto abre el video, usa enlace relativo robusto:
  - ../public/videos/mi-video.html
- Evita enlaces absolutos al dominio cuando quieras compatibilidad local.

6) GIT LFS (SI EL VIDEO ES GRANDE)
- Recomendado para >50 MB.

git lfs install
git lfs track "*.mp4"
git add .gitattributes
git commit -m "chore: track mp4 with git-lfs"

7) COMMIT Y PUSH

git add assets/videos/mi-video.mp4 public/videos/mi-video.mp4 public/videos/index.html public/videos/mi-video.html
git commit -m "feat(videos): add mi-video"
git push origin main

8) VERIFICACION FINAL
- Probar en local:
  - public/videos/index.html
  - public/videos/mi-video.html
- Probar en web:
  - https://<usuario>.github.io/<repo>/public/videos/
  - https://<usuario>.github.io/<repo>/public/videos/mi-video.html
